# 🎮 EPLAY – Loja de Jogos Online

**Eplay** é uma aplicação web desenvolvida em **React com TypeScript** que simula uma loja virtual de games.  
O usuário pode explorar diferentes categorias de jogos, adicionar produtos ao carrinho e finalizar a compra com **boleto ou cartão de crédito**.

---

## 🚀 Tecnologias Utilizadas

- ⚛️ **React** – Biblioteca principal da interface
- 🧠 **Redux Toolkit** – Gerenciamento de estado global (carrinho, checkout, etc.)
- 🧩 **TypeScript** – Tipagem estática e maior segurança no código
- 💅 **Styled-Components** – Estilização dos componentes com CSS-in-JS
- 🧭 **React Router DOM** – Controle de rotas e navegação
- 📦 **Fake API (Fetch / RTK Query)** – Simulação de uma API REST para buscar os jogos
- ✅ **Yup & Formik** – Validação e controle dos formulários de pagamento

---

## 💻 Funcionalidades

- 🕹️ Listagem de jogos por categoria  
- 🔎 Visualização detalhada de cada jogo  
- 🛒 Adição e remoção de itens no carrinho  
- 💳 Finalização de compra com boleto ou cartão  
- 🌐 Consumo de uma **Fake API** com dados simulados  
- ⚙️ Estrutura em **React + TypeScript**, com separação de componentes e hooks

---
